# USDM4 Converter — Frontend

Web interface for the [USDM4-Assure](https://github.com/Lucifer0190/usdm_4_convertor_backend)
backend: upload a clinical trial protocol PDF, follow the conversion to CDISC USDM 4.0 JSON,
and review/certify the extracted fields.

> Work in progress. Development happens on `dev` through feature-branch pull requests.
